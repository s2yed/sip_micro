# 📞 تطبيق الاتصال الصوتي والمرئي الذكي عبر بروتوكول SIP 🚀

> تطبيق موبايل متكامل وعالي الاحترافية تم بناؤه باستخدام **Flutter** لإجراء المكالمات الصوتية والفيديو عبر بروتوكول **SIP (Session Initiation Protocol)** ومقاييس **WebRTC** الحديثة، مع ربطه مباشرةً مع سنترال **Grandstream UCM** الرقمي. تتميز واجهة التطبيق بلمسة جمالية زجاجية فاخرة (Premium Glassmorphic UI) وتفاعل حركي ذكي.

---

## 🏗️ البنية البرمجية والتقنيات المستخدمة (Tech Stack)

*   **Flutter (Dart)**: لبناء واجهات التطبيق بأعلى كفاءة وأداء.
*   **Riverpod**: لإدارة الحالة العامة للتطبيق (State Management) بأسلوب النمط الموزع فائق الاستقرار.
*   **SIP_UA & WebRTC**: لتسجيل الحسابات وإجراء الاتصال المباشر ونقل دفق الصوت والفيديو فائق الدقة.
*   **Flutter Dotenv**: لإدارة وتأمين متغيرات البيئة الحساسة عبر ملفات `.env` المنفصلة.
*   **Permission Handler**: للتعامل الديناميكي والآمن مع صلاحيات الميكروفون والكاميرا.
*   **Flutter Ringtone Player**: لتشغيل نغمات رنين واقعية ومطابقة لأجهزة الهاتف الذكية.

## 🌟 الميزات الجبارة التي تم تنفيذها بدقة واحترافية

### 1. 📲 نظام الاتصال والانتظار المتعدد المتقدم (Advanced Call Waiting)
تم تطوير نظام إدارة مكالمات متقدم يتعامل مع تدفق المكالمات المتزامنة بسلاسة مطلقة:
*   **كشف المكالمات المتزامنة**: عند وجود مكالمة نشطة وتلقي مكالمة أخرى بالخلفية، يعرض التطبيق فوراً إشعاراً علوياً عائماً متميزاً بالتأثير الزجاجي الفاخر.
*   **الرد والتعليق التلقائي (Answer & Hold)**: عند قبول المكالمة الجديدة، يتم وضع المكالمة الحالية تلقائياً قيد الانتظار (Hold)، وتفعيل خط الاتصال مع الطرف الجديد مباشرةً.
*   **إعادة التنشيط الذكي (Unhold/Resume)**: بمجرد إغلاق المكالمة النشطة الحالية، يستشعر التطبيق وجود مكالمة معلقة بالانتظار، ويعيد تنشيطها ووصل الصوت والفيديو معها تلقائياً.

### 2. 🔀 التبديل الفوري والمكالمات الجماعية (Call Swap & Local Conference)
من خلال شريط تحكم عائم في أسفل الشاشة، يستطيع المستخدم إدارة المكالمتين النشطة والملغاة بالخلفية:
*   🔄 **زر تبديل المكالمة (Swap)**: للتبديل الفوري بين الطرفين (وضع النشط قيد الانتظار وتنشيط الآخر) بضغطة زر واحدة ودون انقطاع.
*   🔀 **زر المكالمة الجماعية (Conference)**: لدمج المكالمتين معاً وتفعيلهما في نفس الوقت (Unhold Both) ليتمكن الأطراف الثلاثة من سماع والتحدث مع بعضهم البعض.
*   🔀 **زر فصل المكالمة الجماعية (Split)**: لإعادة تقسيم المكالمة الجماعية وإعادة أحد الأطراف لوضع الانتظار والتحدث مع الآخر بشكل منفرد.

### 3. 🖼️ الشاشات الحركية التفاعلية الفاخرة (Premium Dynamic UI)
تم إعادة تصميم الشاشات لتتوافق مع معايير التصميم الفاخرة:
*   **شاشة الاتصال بالفيديو**: كاميرا أمامية عائمة صغيرة للطرف المحلي مع إمكانية عرض الطرف البعيد بكامل حجم الشاشة.
*   **البطاقات العائمة الذكية**: بطاقة علوية متميزة لعرض رقم المتصل الحالي في مكالمات الفيديو، وبطاقات سفلية لعرض أزرار كتم الصوت وسماعة الأذن ومستوى الصوت.
*   **العرض الديناميكي للأرقام**: قمنا بإلغاء التسميات الثابتة وإظهار أرقام الهواتف أو أسماء الخطوط الحقيقية التي يتم الاتصال بها أو تلقي الاتصال منها فوراً.

### 4. ⚙️ إدارة التهيئة عبر ملف البيئة (.env Configuration)
تأميناً للبيانات وفصلاً للتهيئة عن الشيفرة البرمجية:
*   تم إلغاء كتابة عناوين الـ IP وكلمات المرور يدوياً بداخل الكود.
*   تم دمج نظام قراءة ملفات البيئة `.env` ليسهل التبديل بين بيئة التطوير والإنتاج بمجرد تعديل ملف الإعدادات الخارجي دون لمس الشفرة البرمجية للتطبيق.

## 🛠️ تفصيل الهيكل البرمجي للملفات المعدلة والمطورة

| المسار | الوظيفة التقنية | التغييرات المنفذة |
| :--- | :--- | :--- |
| **`lib/main.dart`** | نقطة انطلاق التطبيق الرئيسية | تهيئة واستدعاء محرك تحميل ملفات البيئة `flutter_dotenv` عند الإقلاع. |
| **`lib/core/config.dart`** | مدير إعدادات خادم UCM و SIP | تحويل الثوابت اليدوية إلى مسترجعات ديناميكية (Dynamic Getters) تقرأ مباشرةً من الـ `.env`. |
| **`.env`** | مستودع الإعدادات والمتغيرات الحساسة | تخزين عنوان الخادم UCM، منافذ WS/WSS، المسار اللاسلكي، وكلمة السر الافتراضية. |
| **`lib/features/voip/sip_provider.dart`** | المحرك الأساسي لإدارة المكالمات (Notifier) | برمجة كامل الدوال الخاصة بـ `acceptWaitingCall`, `swapCalls`, `mergeIntoConference`, `splitConference` وإدارة حالات المكالمات. |
| **`lib/features/voip/call_screen.dart`** | واجهة المستخدم المتقدمة | بناء وتنسيق الواجهات الزجاجية المتجاوبة وإدراج أزرار التبديل والمكالمة الجماعية والنافذة العائمة المضيئة. |
| **`packages/sip_ua/.../rtc_session.dart`** | مكتبة اتصالات WebRTC الأساسية | ترشيح وتنقية معالجات كوديك الصوت (SDP Codec Filter) لتجاوز مشكلة توافقية UCM وسماعات أجهزة الأندرويد الحديثة. |

## 🚀 طريقة التشغيل والتهيئة السريعة

1. قم بتهيئة ملف الـ `.env` في المجلد الرئيسي بالبيانات الصحيحة:
   ```env
   UCM_HOST=192.1.1.2
   UCM_WSS_PORT=8089
   UCM_WS_PORT=5000
   UCM_WSS_PATH=/ws
   SIP_PASSWORD=ssss
   ```
2. قم بتحميل الاعتمادات الجديدة:
   ```bash
   flutter pub get
   ```
3. ابدأ تشغيل التطبيق بالكامل:
   ```bash
   flutter run
   ```
